# 步驟 13 履約管理

（先讀 steps/_common-memo.md）

這一步是「停留」階段：履約期間可能很長，每次 /bid-run 進到這裡都做下列事：
1. 更新 `13-performance-log.md`（開工、進度、估驗、展延、逾期）。
2. 問承辦人是否有契約變更、後續擴充或分期驗收需求：
   - 有 → `procure.py add 契變`／`add 後續擴充`／`add 分期驗收`（會插在本階段之後；若要立即處理加 `--now`），然後 submit 本階段，等確認後進入臨時階段。
   - 沒有、且已竣工 → submit，確認後進入驗收。
   - 沒有、尚未竣工 → submit 並說明「履約中，下次 /bid-run 再更新」；承辦人可回覆「暫停」維持現狀。
3. submit，請承辦人確認紀錄與是否插入臨時階段。
