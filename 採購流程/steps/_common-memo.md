# 後段簽呈共通規則（步驟 7 以後都適用）

- 簽呈格式比照 03-approval-memo（簽 於總務組、主旨、說明、擬辦、敬陳 處長、承辦單位電話列）。`reference/舊檔/` 有同類簽呈時以其用語為準。
- 階段資料夾內的 `.md` 是工作稿（含表格與擬稿提示）。簽呈完稿另存同名 `.txt`（每行一段），再執行
  `python3 採購流程/scripts/build_memo_docx.py <txt> <docx>`；紀錄、表格類用 `procure.py export --stage <資料夾名>`。
- 開標家數、廠商名稱、報價、評分、驗收結果等「事實」只能來自承辦人或業務單位提供的資料（放 00-input/ 或階段資料夾）；沒有就留 【待補：…】 並在回合結束時列出需要承辦人提供的資料。
- 日期用 `scripts/schedule.py` 或 python 計算；金額比率用程式算並附算式。
- 法條只引用 references/ 或來源檔已出現者，沒把握標 【請確認條號】。
- 做完：`procure.py submit` → 結束回合 → 列出本步成果、待確認事項、需要承辦人補的資料。
