# 步驟 9 評選／評審

（先讀 steps/_common-memo.md）

1. 若委員會尚未另案成立，先擬 `09-committee-memo`（委員人數、專家學者比例 ≥ 1/3、召集人層級、資料庫來源）；本處慣例由業務單位另案陳核者，此檔註明「由業務單位另案陳核」即可。
2. 取得評選會議資料：出席委員、各委員評分表或序位表、廠商簡報順序。用 python 重算總評分／序位和並附算式；檢查出席人數（≥ 總數 1/2 且專家學者 ≥ 1/3）、價格權重 ≥ 20%、評分差異逾規定者是否有說明。
3. 填 `09-evaluation-record.md`，擬 `09-evaluation-result-memo`（優勝序位；是否需議價：未訂底價案標價在預算內免議價，逾預算者依序議價）。
4. 提醒：委員名單、評分於決標後公開；評選紀錄送監辦簽章。
5. submit，請承辦人確認會議紀錄與結果簽呈。
