# 核對規則與易錯點

步驟 4 逐項核對，每項寫「一致／不一致／來源缺漏」並附兩邊原文與出處。

## A. 金額與保證
- [ ] 預算金額、採購金額：業務簽、預算書、招標資訊一覽表、公告稿、投標須知、簽呈全部相同。
- [ ] 預算金額不是預算書總計（總計含委託技術服務費、工程管理費）。
- [ ] 押標金 ≤ 預算金額 5%。
- [ ] 履約保證金、保固保證金比率與契約書、投標須知一致。
- [ ] 預算金額逾 500 萬：確認有工務局免代辦函，或依代辦程序。

## B. 日程
- [ ] 等標期符合招標期限標準（公告金額以上未達查核金額：14 日）。
- [ ] 公告日至截止投標日天數與等標期相符。
- [ ] 釋疑：廠商提問期限 = 等標期 ÷ 4 進位；**機關最後答覆日的次日起算至截止投標日，天數不得少於等標期四分之一**（尾數以 1 日計）。
  - 11506 舊檔：等標期 14 日 → 4 日。公告稿：提問至 12/1，答覆 12/8，截止 12/11；12/9～12/11 僅 3 日，請在新案用實際日曆重算。
- [ ] 開標日、地點與投標須知、公告稿一致；日期避開假日。
- [ ] 第 2 次招標縮短等標期的依據與日期（若適用）。

## C. 法條與方式
- [ ] 最有利標：採購法第 52 條第 1 項第 3 款（舊檔簽呈說明七(五)1 誤為第 2 款）。
- [ ] 第 56 條第 3 項上級機關核准函文號與公告稿「核准文號」一致。
- [ ] 不訂底價依據：採購法第 47 條第 1 項第 2 款。
- [ ] 價格納入評比且權重 ≥ 20%（舊檔 20%）。

## D. 評選
- [ ] 評選項目權重加總 100；評選須知、評比表、簽呈一致。
- [ ] 評選委員名單已由處長核定排序（xlsx「核定排序」欄不得空白）；公告前完成登載。
- [ ] 召集人層級：預算 500 萬以上由主任秘書以上擔任。
- [ ] 專家來源與迴避：非工程會資料庫人選要有說明；近期出席率異常者提醒。
- [ ] 評選須知範本版本（舊檔 D.1 V23.1 113/10/21）是否仍為最新，到 gpis.taipei 查。

## E. 標單與預算書
- [ ] 總表、詳細價目表、單價分析表的百分比、編號互相對得上。
  - 11506 業務單位 ods 發現：職安費總表 0.8% / 單價分析 0.5%；材料檢驗費總表 0.8% / 單價分析 0.1%；詳細價目表「柱面裂縫修復」標單價分析 07，實際為 06（07 是裂縫灌注）。
- [ ] 預算書已有會計單位與機關首長用印（舊檔預算書首頁欄位空白，簽呈擬辦三要求用印）。
- [ ] 圖說索引頁數與實際頁數相符（舊檔 14 張）。

## F. 文件完整
- [ ] 招標文件清單數量為 1 的項目都有檔案；數量為 0 的確實不需要。
- [ ] 開工管制條件檢核表（附件10）有檔案且已用印。
- [ ] 自檢表 A1、A2 為最新版（舊檔 A.1 V22.0 114/08/15、A.2 V17.0 114/7/24），逐項勾選完成。
- [ ] 契約書、投標須知範本的修頒函號是否為最新。
- [ ] 案名在所有文件一致（工務局函舊檔誤寫「2樓（穿堂）」，應為「1樓穿堂」）。

## G. 公告稿
- [ ] 評選委員名單已登載（舊檔 11/25 暫存稿顯示「未登載」）。
- [ ] 聯絡人、分機、截止時間、地點與簽呈一致。
- [ ] 是否適用 GPA、ANZTEC、ASTEP 判斷與招標資訊一覽表一致。

## H. 開標、評選、決標（新增）
- [ ] 開標時間、地點與公告一致；監辦單位已通知並到場或書面監辦。
- [ ] 投標廠商家數：第 1 次公開招標未達 3 家不得開標（採購法第 48 條）；第 2 次不受此限。
- [ ] 資格審查項目只限投標須知所列，不得增加。
- [ ] 評選：出席委員達委員總數 1/2 以上且專家學者 1/3 以上（採購評選委員會審議規則）；評分與序位計算用程式重算。
- [ ] 最有利標評定後，無底價案的議價：以評選優勝廠商之標價為準，逾預算者議減。
- [ ] 決標公告於決標日起 30 日內刊登（採購法第 61 條）；決標金額、廠商統編與決標紀錄一致。

## I. 簽約、履約、驗收（新增）
- [ ] 履約保證金金額＝契約金額 × 比率，繳納方式合於擔保作業辦法；簽約期限內完成簽約。
- [ ] 契約金額、工期、付款條件與決標紀錄、投標須知一致。
- [ ] 契約變更：變更金額累計是否逾原契約金額一定比率而須另案辦理；工期展延依據（契約第 7 條、第 20 條）。
- [ ] 後續擴充：原公告與招標文件已敘明期間、金額或數量；擴充總額不逾公告上限；於原契約期限內辦理。
- [ ] 驗收：工程竣工後 7 日內（契約規定）通知初驗；初驗合格後 20 日內驗收（施行細則第 93 條）；驗收紀錄載明採購法第 72 條事項。
- [ ] 減價收受須符合採購法第 72 條第 2 項，並經機關首長或其授權人員核准。
- [ ] 保固保證金於驗收合格後收取，保固期自驗收合格日起算。
