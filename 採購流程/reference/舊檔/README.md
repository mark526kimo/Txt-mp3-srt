# 舊檔（歷史案件）

把已核定的舊案文件放在這裡，Claude 擬稿時會先讀，作為格式與用語依據。
建議依案號建子資料夾，例如：

```
reference/舊檔/11506/
  11506_招標文件核定簽呈.txt      ← 簽呈全文（純文字最好）
  11506_招標資訊一覽表.pdf
  11506_公告稿.pdf
  11506_開標紀錄.pdf  11506_評選會議紀錄.pdf  11506_決標簽.pdf  11506_驗收簽.pdf …
```

- 純文字或 docx 最容易讀；PDF 會用 pdftotext 轉；掃描檔會逐頁看圖。
- 舊檔裡的日期、文號、金額、人名只是格式參考，**不得**帶進新案。
- 原架構提到的 `example-11506-approval-memo.txt`（11506 案已核定簽呈全文）請放到 `reference/舊檔/11506/`，
  `templates/03-approval-memo.md` 就是依它整理的範本。
