# 法規（擬稿時的法源依據）

把您桌電上整理好的法規放在這裡，Claude 擬稿與核對時會先讀，條號只引用這裡或 references/ 已出現的內容。
建議放（檔名自取，PDF、docx、txt 皆可）：

- 政府採購法、施行細則
- 招標期限標準、押標金保證金暨其他擔保作業辦法、投標廠商資格與特殊或巨額採購認定標準
- 最有利標評選辦法、採購評選委員會組織準則與審議規則
- 機關委託技術服務廠商評選及計費辦法（如適用）
- 工程採購契約範本、投標須知範本（記下版本與修頒日期）
- 本處或臺北市政府的分層處理原則、代辦作業程序、自我檢核表

法規會修正，檔名請含日期或版本，例如：`政府採購法_113.xx.xx修正.pdf`。
